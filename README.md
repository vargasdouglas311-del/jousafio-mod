# JOUSAFIO 1.16.5 Forge

## Para obtener el .jar real:
1. Necesitas JDK 8 instalado
2. En esta carpeta ejecuta: ./gradlew build
3. El jar aparece en build/libs/jousafio-1.16.5-1.0.0.jar

## Contenido del mod
- Comando /ruleta <color> <mensaje>
- Momento Safio (roja) y Momento Safion (rosa)
- Menu de cambios de dificultad
- /ruleta mision (mision diaria)
- Armadura Safio completa + Espada + Cuchara de Resurreccion + Totem + Alma
- Texturas 256x256
- Cambios: sandwich, botones letales, gas toxico, lluvia fuego, etc.
